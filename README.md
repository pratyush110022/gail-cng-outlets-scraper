# GAIL CNG Outlets Scraper

A Python project for collecting and organizing GAIL CNG outlet information
by area, with an Excel dataset for Bengaluru Urban and Rural districts.

## Project Files

- `GAIL_Gas_CNG_Outlets_Area_Wise.py` — main Python script
- `GAIL_Gas_CNG_Outlets_Bengaluru Urban & Rural District.xlsx` — sample dataset

## Setup

Create a virtual environment:

    python -m venv .venv
    .venv\Scripts\Activate.ps1

Install the dependencies required by the script.

Review the Python imports and install the relevant packages using pip.

## Run

    python GAIL_Gas_CNG_Outlets_Area_Wise.py

## Notes

Dataset coverage, freshness, and completeness depend on the source data
and the script's implementation. Check applicable source terms and
permissions before redistributing the dataset.
